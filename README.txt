EUROPEAN COURTYARD — INTERACTIVE PORTFOLIO V2

打开方式：
1. 解压整个文件夹。
2. 双击 index.html。
3. 不要把 assets 文件夹单独拿走；index.html 需要它里面的图片。

这个版本不是把 PPT 一页页放进网页，而是把 PPT 里的图片拆出来作为交互场景：
- Masterplan：点击中央庭院 / 水院 / 几何花园 / 草坪房间
- Plan Annotation：点击 ARRIVE / DISCOVER / PAUSE / RELEASE / WATER ISLAND / BRIDGE / FOUNTAIN
- Landscape Nodes：点击鸟瞰图上的三个节点
- Design Direction：点击 AXIS / FRAME / REFLECTION / GARDEN ROOM
- Concept Sketch：点击草图编号
- Design Analysis：点击 CIRCULATION / WATER SYSTEM / PLANTING
- Detail Language：点击材料
- Perspectives：切换鸟瞰图与手绘透视
